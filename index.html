P0 NATIVE

Player 0 keeps Windows.

Your main keyboard and mouse stay normal. Use the desktop, launchers, and game windows like usual.

P1+ ROUTED

Extra players get their own controls.

Weaver's guided setup assigns selected keyboards and mice to player slots for supported game adapters.

SUPPORTED ADAPTERS

Minecraft and Paralives.

Install the game-side adapter, start Weaver, and launch the game instances you want to play.

Lattice Weaver

The Windows companion app handles player slots, guided setup, device assignment, profile selection, and adapter connections.

Minecraft master controls

Player 0 can adjust routed-player Minecraft settings from a purpose-built in-game control screen.

Paralives adapter

Route another player's input into Paralives while your native Windows controls remain available.

Developer devkit

Build game adapters against the public adapter surface. Weaver remains closed-source; the devkit contains schemas, samples, and SDK libraries.
