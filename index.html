How it works

Lattice Weaver is the companion app for the Lattice mod on Modrinth. Install the free mod into each Minecraft instance, run Lattice Weaver, assign a mouse and keyboard to each player slot, and every player gets their own game window on the same PC.

  • 45-minute free trial — active playtime only, no card required
  • One-time $14.99 license unlocks unlimited use
  • Activation is one POST — offline forever after

After you buy

Polar emails your key instantly. Activate with:

lattice-weaver.exe --unlock latw-XXXXX-XXXXX-…

One key per PC. To transfer to a new machine, re-run the unlock command from there — the server auto-rebinds after a 365-day cooldown, or email support@bide.cx for a faster rebind.

Compatibility

  • Windows 10 or 11
  • Fabric-loader Minecraft (1.20.1, 1.21.1, 1.21.8, 1.21.10, 26.1)
  • Interception kernel driver recommended (the companion prompts you to install it on first run if missing)
