Lattice Weaver v2.0.0

Couch co-op for your PC. One screen, several players, each with their own mouse and keyboard.

Lattice Weaver gives each player their own devices and routes them into supported games. Several people can play side by side on one PC. Each player runs their own instance and stays in full control of their own input.

What's new in v2

A full generational step: faster, simpler setup and more reliable device handling.

Claim a device with no reboot and no replug

Claiming a device is now in-place. Weaver activates the driver it needs without asking you to pull a dongle or restart the PC. Setup runs in a straight line, from plugging in to playing.

All-in-one devices route completely

Some devices present several inputs on one connection. Weaver claims and routes every input from that one device to the same player, so an all-in-one controller works as a single device for that seat.

Mice that report oddly now route correctly

Mouse calibration works immediately and learns a mouse's button, axis, and scroll layout from use. A guided manual calibration is always the authority, so you can map any mouse exactly. Clicks and scroll land where you expect.

Clear routing state, no surprises

In supported games, each instance shows when its input is paused or disconnected. Reconnecting a device never re-enables routing on its own. Turning input back on is always your call.

See the interface before you download

This is the real Weaver companion app, running right here in your browser. Open the dashboard, switch themes, run the guided setup, and explore every screen. It is visual only. No devices are touched.

How it works

1

Install Lattice Weaver and run it

It opens a guided setup.

2

Assign devices by using them

When Weaver asks, move the mouse or press a key on the set you want for Player 1, then Player 2, and so on. Whatever you actuate is claimed for that slot. Player 1 keeps native control. Extra players drive their own instance.

3

Launch one game instance per player

Weaver routes each player's claimed mouse and keyboard to their own instance.

Questions

Hover or tap a card to flip it over for the answer.

  • Q

    Do I need a second monitor?

    Flip for the answer

    No. Everyone shares one screen, and each player gets their own tab. A second monitor is nice to have, not required.

  • Q

    What do I need per player?

    Flip for the answer

    One mouse and one keyboard each. Player 1 can use the PC's main set.

  • Q

    Does claiming a device need a reboot?

    Flip for the answer

    No. v2 activates devices in place, with no replug and no restart.

  • Q

    My mouse's clicks or scroll went to the wrong place. How do I fix it?

    Flip for the answer

    Run the guided calibration for that mouse during setup. Calibration learns the layout from use, and the manual pass is the authority, so input routes correctly.

  • Q

    Can I use a game controller?

    Flip for the answer

    Not yet. Lattice does not route gamepads at this time. For controller input, use a controller mod such as MidnightControls or Controlify. That is separate from Lattice.

  • Q

    Which platforms are supported?

    Flip for the answer

    Windows is stable. macOS is in alpha. Linux is planned. Testers can ask for access at support@bide.cx.

  • Q

    Is the Minecraft mod separate?

    Flip for the answer

    The Minecraft mod is free on Modrinth (slug latticework). Weaver is the companion that does the device claiming and routing.
